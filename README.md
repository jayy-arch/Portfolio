About This Project

This is my personal portfolio website. I'm Josephine Ilunga, an upcoming software engineer, and this site is my professional home on the web. It is where employers, recruiters, collaborators and fellow developers can learn who I am, what drives me, and what I have built.
This portfolio is not just a list of projects. It tells the story of a developer who is at the start of a long build, who is more curious than certain, and who cares more about the process of learning and creating than about a finished product. I treat "upcoming" as a description of momentum, not a lack of experience.

Purpose and Goals

I built this portfolio to:
Introduce myself as a developer with personality, not just a list of skills.
Show real work: practical projects built with Java, SQL, HTML, CSS and JavaScript.
Communicate my mindset. I'm not interested in building ordinary things just because they work. I want to build things that make people feel something.
Show that I'm open to opportunities, including internships, junior roles, freelance work and collaborations.
Make it easy for anyone who wants to work with me to get in touch.

Who It Is For

I made this site for:
Recruiters and hiring managers who want a quick picture of my skills, projects and attitude, and a way to contact me.
Potential collaborators who want to see what I'm interested in and the kind of work I enjoy building.
Clients who want examples of working applications and to understand how I approach problems.
Other developers and peers who want to read the source code of my projects on GitHub.
About Me

I'm a developer who:

Is curious first. I'm more interested in understanding how things work than in having every answer.
Learns by taking things apart. Most days that means breaking small things on purpose to understand how they work.
Treats creativity as part of engineering. Outside of code, I love to dress as if it's a creative practice, and I say yes to activities I haven't tried yet.
Sees "upcoming" as momentum. I'm early in my career, but I'm building steadily and deliberately.
My one-line pitch: I turn curiosity into interfaces, ideas into products, and technology into experiences people remember.

My Interests and Philosophy

This portfolio is built around one idea: building things that make people feel. Three interests shape my work.
Design. I love exploring where design and technology meet, and how they can be used together to create meaningful experiences for users. To me, good software is not only correct, it is thoughtful and pleasant to use.
Development. I enjoy building web applications and experimenting with new technologies to create innovative solutions. Development is where my curiosity turns into something real.
Culture. I'm fascinated by how culture influences technology and how technology shapes culture in return. I want to create products that resonate with diverse audiences, not just a narrow group of users.
Projects I Showcase
I've included four projects. Together they show my range across back-end logic, databases, desktop interfaces, games and front-end web development. Each one links to its source code on GitHub.

1. Banking System (Java and SQL). I built a banking application that lets customers manage their accounts, deposit money and withdraw funds. It uses Java for the application logic and SQL for the database. This project shows my work with object-oriented design, database queries, and handling financial transactions and data.

2. Java Swing Data Capture Application. I built a desktop application with a graphical interface that captures data using Java Swing. It shows my experience with GUI development, forms, input handling and event-driven programming.

3. Rock-Paper-Scissors Game (Java). I
 built a classic Rock-Paper-Scissors game in Java where the player competes against the computer. It shows my grasp of control flow, game logic and clean program structure.

4. To-Do List Application (HTML, CSS and JavaScript). I built a web-based task manager with HTML, CSS and JavaScript. It shows my front-end skills, including interactivity, layout and user-friendly design.
